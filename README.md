# Semantic Scout

Share pack for the **Semantic Scout** Cursor skill (rate Jira vs your branch before you open a PR).

| File | What it is |
|------|------------|
| [DOCUMENTATION.html](DOCUMENTATION.html) | Team guide — open in a browser |
| [share-image.svg](share-image.svg) | Hero image for Slack or decks |
| [SKILL.md](SKILL.md) | Cursor skill — install once (below) |

## Setup (about 5 minutes, once)

1. Copy `SKILL.md` to `%USERPROFILE%\.cursor\skills\semantic-scout\SKILL.md` (create the `semantic-scout` folder if needed).
2. In Cursor chat, type: **Setup Semantic Scout**
3. Prove it: **Semantic Scout for AN-XXXX** (use your real ticket)

Nothing else in this repo is required for day-to-day use.
